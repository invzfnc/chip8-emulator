# CHIP-8 Emulator

## Requirements and dependencies

I'm running this with MSYS2 UCRT64 toolchain on Windows, using the g++ compiler and mingw32-make. SDL3 is used to render graphics on screen, and is installed with the MSYS2 pacman package manager:

```
pacman -S mingw-w64-ucrt-x86_64-sdl3
```
